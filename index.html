The Story

Practical beats impressive.

Every system I've shipped started as a real problem someone was living with — paper-heavy clinic records, chaotic food orders in a crowded café, commuters guessing at routes. I earned my BS in Computer Science at Mapúa Malayan Colleges Mindanao, stacked twenty-nine certificates along the way, and kept one rule: build the thing people will actually use.

  • 01

    Ship things people use

    A project isn't done when the code compiles — it's done when a nurse, a cashier, or a commuter reaches for it without being told to.

  • 02

    The interface is the product

    Users never see the schema. I design screens first in Figma, then build backends that keep the promises the interface makes.

  • 03

    Boring tech, done well

    PHP and MySQL where they fit, React and Supabase where they help. The stack serves the problem — never the other way around.

  • 04

    Learn relentlessly

    From CCNA networking to large language models — twenty-nine courses and counting, each one pulled into a real build within months.
